# EX No.5.1.DESIGN THE 3D MODEL AS PROVIDED AND CONVERT TO ORTHOGRAPHIC VIEW
## DATE:

## AIM: 
To create orthographic view of given 3D model

## REQUIREMENTS: 
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:
Part 1 – Create the base flange
Step 1: Create a new design
Open Autodesk Fusion 360.

Click File → New Design.

Click Create Sketch.

Select the XY plane.

Step 2: Draw the base outline
Select Line (L) and draw the central portion of the flange.

Use the Arc tool to draw the rounded outer edges.

Create the left and right mounting extensions.

Connect the arcs and lines to form one closed profile.

Use the Trim (T) tool to remove unwanted portions.

Click Finish Sketch.

Step 3: Extrude the base
Press E (Extrude).

Select the base profile.

Enter the base thickness according to the drawing.

Select New Body.

Click OK.

Your base flange is ready.

Part 2 – Create the central circular boss
Step 4: Draw the boss
Select the top face of the flange.

Click Create Sketch.

Select Circle → Center Diameter Circle.

Draw a circle at the centre of the flange.

Press D and enter the outer diameter of the boss according to the drawing.

Click Finish Sketch.

Step 5: Extrude the boss
Press E to open the Extrude tool.

Select the circular profile.

Enter the required boss height.

Set the operation to Join.

Click OK.

The central raised boss is now complete.

Part 3 – Create the central bore
Step 6: Draw the centre hole
Select the top face of the central boss.

Click Create Sketch.

Select Circle → Center Diameter Circle.

Draw a circle at the centre.

Enter the inner diameter according to the drawing.

Click Finish Sketch.

Step 7: Cut the bore
Press E (Extrude).

Select the inner circle.

Set Operation → Cut.

Set the extent to Through All.

Click OK.

Your central bore is completed.

Part 4 – Create the mounting holes
Step 8: Draw the bolt holes
Select the top face of the flange.

Click Create Sketch.

Select Circle → Center Diameter Circle.

Draw the mounting holes at the positions shown in the top view.

Enter the hole diameters according to the drawing.

Position the holes symmetrically around the central boss.

Click Finish Sketch.

Step 9: Cut the mounting holes
Press E.

Select all the mounting-hole circles.

Change Operation → Cut.

Select Through All.

Click OK.

All mounting holes are now created.
<img width="337" height="376" alt="Screenshot 2026-11-24 192545" src="https://github.com/user-attachments/assets/123946ad-f363-4275-b331-c1301f46c73a" />

Part 5 – Create the stepped circular features
Step 10: Create the circular step
Select the top face of the central boss.

Click Create Sketch.

Draw the additional concentric circles required for the stepped portion.

Apply the diameter dimensions according to the drawing.

Click Finish Sketch.

Step 11: Extrude or cut the step
Press E.

Select the required ring-shaped profile.

Enter the step height or depth according to the section view.

Choose Join for raised material or Cut for recessed material.

Click OK.
<img width="418" height="202" alt="Screenshot 2026-11-24 192610" src="https://github.com/user-attachments/assets/f0ee5ad6-818d-4e77-bbb4-41e4daac7c03" />

Part 6 – Create the side and bottom recesses
Step 12: Draw the recesses
Rotate the model to the side view.

Select the required face and click Create Sketch.

Use the Circle or Rectangle tool to draw the recess profile.

Apply the dimensions according to Section A–A and Section B–B.

Click Finish Sketch.

Step 13: Cut the recesses
Press E (Extrude).

Select the recess profiles.

Choose Cut.

Enter the required depth.

Click OK.

Part 7 – Apply fillets and finish the model
Step 14: Apply fillet
Click Modify → Fillet.

Select the required outer edges.

Enter the radius according to the drawing.

Click OK.

Step 15: Final checking
Rotate the model using the ViewCube.

Check the central boss and bore.

Check all mounting holes.

Check the stepped and recessed features.

Compare the model with the isometric drawing.

Save the design using Ctrl + S.
